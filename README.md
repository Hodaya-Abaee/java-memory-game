# Memory Game (Java Swing)

A simple Memory Card Game built with Java Swing as a desktop application.  
The game supports 2 players, score tracking, and multiple difficulty levels.

## 🎮 Features
- 2-player turn-based gameplay
- Card matching logic with scoring system
- Difficulty levels (Easy / Medium / Hard)
- Randomized board each game
- Win detection and winner announcement
- Play again / restart game option
- Image-based cards (custom assets)

## 🛠 Technologies
- Java
- Swing (GUI)
- OOP Principles
- Event-driven programming

## 🧠 How to Run
1. Clone the repository
2. Open the project in Eclipse / IntelliJ
3. Run `Main.java`

## 📌 Notes
This project was built as a learning exercise to practice OOP design, GUI development, and event handling in Java.
